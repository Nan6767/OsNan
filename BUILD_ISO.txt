#      (push-триггер смотрит на этот файл).

#   slim — оба окружения (Hyprland + KDE Plasma) без дополнительных наборов,

#          (может не влезть в место стандартного раннера).
#
#   mini — компактный образ < 2 ГБ: влезает в релиз GitHub ЦЕЛЬНЫМ файлом
#          (лимит релиза — 2 GiB). Оба окружения и Firefox на месте, вырезаны
#          второе ядро, компиляторы, тяжёлые шрифты и мессенджеры.
