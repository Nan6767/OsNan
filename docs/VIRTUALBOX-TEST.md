# Проверка FlyArchOs 1.8.0-beta в VirtualBox

Этот чек-лист нужен для первого полного ручного теста кандидата:
live-загрузка → Calamares → офлайн-установка → первая загрузка установленной
системы. Автоматические проверки CI подтверждают состав образа, но не заменяют
этот сценарий.

> Если VirtualBox настраивается впервые, сначала выполните общее руководство
> **[VIRTUALBOX.md](VIRTUALBOX.md)**: там пошагово разобраны подключение ISO,
> создание ВМ, сеть, Guest Additions, общие папки и USB. Затем вернитесь к
> этому чек-листу для строгой проверки бета-кандидата.

## 1. Какой образ тестировать первым

Используйте **Mini №59** — актуальную сборку FlyArchOs 1.8.0-beta с
исправленным запуском Calamares, кнопкой установки в live-помощнике и
гостевыми утилитами VirtualBox. В её CI-логе подтверждены установленные
`calamares` и `virtualbox-guest-utils`, модуль `packagechooser` и финальная
проверка содержимого образа. Mini №59 заменяет №58 для этого E2E-теста:

- ISO одним файлом: <https://github.com/Nan6767/OsNan/releases/download/iso-59-mini/flyarchos-1.8.0-beta-x86_64.iso>
- Релиз: <https://github.com/Nan6767/OsNan/releases/tag/iso-59-mini>
- Размер: `1 913 618 432` байта
- SHA-256: `48fb7e8ad9347fd78ce53ec3fc9a3f8240ca80776b90e2ae1c8b0c9d9183e5fa`
- Лог сборки: [../logs/iso-run-59.log](../logs/iso-run-59.log)

Проверка контрольной суммы в PowerShell:

```powershell
Get-FileHash .\flyarchos-1.8.0-beta-x86_64.iso -Algorithm SHA256
```

Не используйте для этого теста образы №49–№55: в них найдены дефекты
установщика, а в старых образах Calamares вообще не попадал в ISO из-за
игнорируемого mkarchiso файла `packages.aux`.

## 2. Настройки виртуальной машины

- VirtualBox 7.x;
- тип: **Arch Linux (64-bit)**;
- **Skip Unattended Installation**;
- RAM: 12 ГБ, CPU: 4, диск VDI: 40 ГБ;
- **Enable EFI**: да, Secure Boot: нет;
- видеоконтроллер: **VMSVGA**, видеопамять: 128 МБ, 3D-ускорение: да;
- порядок загрузки: оптический диск первым;
- ISO подключён в виртуальный оптический привод.

Если Hyprland после пароля возвращает экран SDDM, сначала проверьте, что
3D-ускорение **включено**: без него сессия Hyprland в VirtualBox может сразу
завершаться. Отключение 3D допустимо только как отдельная ветка проверки с
входом в Plasma при артефактах/чёрном экране; результат запишите отдельно, а
не считайте автоматическим провалом установщика.

## 3. Live-загрузка

1. В меню загрузки выберите обычный пункт FlyArchOs.
2. Дождитесь автоматического входа в Hyprland.
   - Live-пользователь: `fly`
   - Пароль: `flyarchos`
3. Отметьте, что видно:
   - [ ] обои;
   - [ ] панель Waybar;
   - [ ] мышь и клавиатура работают;
   - [ ] движение мыши и окон приемлемо без заметной задержки;
   - [ ] меню приложений открывается по `Super+D`;
   - [ ] терминал открывается по `Super+Enter`;
   - [ ] в приветственном окне видна кнопка **«Установить FlyArchOs на диск»**.

Если SDDM вместо автовхода показывает экран входа, выберите Hyprland и войдите
как `fly / flyarchos`. Для проверки второго окружения можно завершить сеанс и
выбрать Plasma.

Если графика заметно тормозит, запишите разрешение окна ВМ, число CPU/RAM и
состояние 3D. В Mini №59 режим производительности для ВМ должен включиться
автоматически; проверьте `flyarchos-performance status` и при необходимости
используйте раздел «Медленно» в [VIRTUALBOX.md](VIRTUALBOX.md).

## 4. Запуск установщика

1. В приветственном окне нажмите **«Установить FlyArchOs на диск»**.
2. Если окно уже закрыто, нажмите `Super+D`, введите `Install` и запустите
   **Install FlyArchOs**.
3. Терминал и ручные команды для запуска не нужны. Если кнопка или ярлык не
   открыли Calamares, это регрессия именно проверяемой сборки: запишите
   результат, сделайте скриншот и соберите данные из раздела 7. Запасная
   команда для диагностики — `flyarchos-install` в терминале
   (`Super+Enter`).

Calamares должен открыться без запроса пароля: в live-сессии у пользователя
`fly` настроен sudo без пароля.

- [ ] Calamares открылся;
- [ ] видны страницы приветствия, региона, клавиатуры и разметки;
- [ ] есть страница выбора рабочего окружения;
- [ ] есть страница выбора загрузчика.

Для mini страниц «Сценарий установки» и «Наборы ПО» быть **не должно** — в
компактном образе тяжёлых наборов нет. Для full №57 обе страницы должны быть.

## 5. Базовый сценарий установки

Для первого прогона выбирайте самый простой вариант:

| Шаг | Значение для базового теста |
|---|---|
| Язык | Русский |
| Часовой пояс | ваш регион |
| Клавиатура | обычная PC, US/RU по желанию |
| Разметка | **Стереть диск** |
| Файловая система | **btrfs** |
| Swap | **swap-файл** |
| Шифрование | **выключено** для первого теста |
| Окружение | **Hyprland + KDE Plasma** |
| Загрузчик | **GRUB** |
| Пользователь | создать нового пользователя и задать пароли |

На странице сводки проверьте, что выбран именно виртуальный диск на 40 ГБ.
Затем запускайте установку и не выключайте ВМ до страницы завершения.

Отдельные повторные тесты после успешного базового прогона:

- только Hyprland;
- только Plasma;
- systemd-boot на EFI;
- LUKS;
- full №57 с пресетом и дополнительными наборами ПО.

## 6. Первая загрузка установленной системы

1. После завершения установки **не нажимайте сразу перезагрузку**, если ISO
   всё ещё стоит первым загрузочным устройством.
2. В VirtualBox откройте **Devices → Optical Drives** и извлеките ISO.
3. Перезагрузите ВМ.
4. GRUB должен загрузить установленную систему с виртуального жёсткого диска.
5. Войдите через SDDM под созданным пользователем.

Проверьте обе сессии, если на шаге установки было выбрано «оба окружения»:

- [ ] вход в Hyprland работает;
- [ ] вход в Plasma работает;
- [ ] сеть работает;
- [ ] звук работает или хотя бы виден аудиовыход;
- [ ] обои отображаются;
- [ ] система переживает ещё одну перезагрузку.

В установленной системе полезно выполнить:

```bash
flyarchos-info
systemctl --failed
pacman -Q calamares
ls -l /usr/share/applications/flyarchos-install.desktop
```

Ожидаемый результат:

- `flyarchos-info` запускается;
- критичных упавших служб нет;
- `pacman -Q calamares` пишет, что пакет не найден;
- ярлыка установщика в установленной системе нет.

## 7. Что прислать при ошибке

Не удаляйте ВМ сразу. Нужны:

1. На каком этапе остановилось: загрузка ISO, live, страницы Calamares,
   процент установки, первая загрузка или вход в окружение.
2. Скриншот ошибки.
3. Выбранные параметры: EFI/BIOS, ФС, шифрование, окружение, загрузчик.
4. Если доступен терминал live-сессии, последние строки логов:

```bash
sudo tail -n 300 /root/.cache/calamares/session.log
journalctl -b --no-pager | tail -n 200
```

Если установленная система хотя бы частично загружается:

```bash
sudo tail -n 300 /var/log/flyarchos-install.log
sudo tail -n 300 /var/log/flyarchos/profile.log
systemctl --failed
journalctl -b --no-pager | tail -n 200
```

Если Calamares не открывается, дополнительно выполните в live-терминале:

```bash
which calamares
pacman -Q calamares
ls /usr/lib/calamares/modules/packagechooser/
flyarchos-install
```

## 8. Критерий успеха

Кандидат считается прошедшим первый E2E-тест, если одновременно:

- ISO загружается в live-сессию;
- Calamares открывается и показывает применимые страницы выбора;
- офлайн-установка доходит до финиша без ручного вмешательства;
- установленная система загружается с виртуального жёсткого диска;
- можно войти в выбранное окружение под созданным пользователем;
- Calamares отсутствует в установленной системе.

До этого результата FlyArchOs 1.8.0-beta Mini №59 остаётся кандидатом для
проверки, а не доказанно рабочей стабильной системой.
