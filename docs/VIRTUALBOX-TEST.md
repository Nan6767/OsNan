# VirtualBox: проверка live-образа NanOs

## Первый критерий

Проверяем только цепочку **EFI → Kali live → автоматический вход → Hyprland**. Установка на диск пока не входит в 0.0.1-alpha.

## Настройки виртуальной машины

- Тип: Linux, Debian (64-bit) или Kali Linux (64-bit).
- ОЗУ: 4 ГБ минимум (рекомендуется 6 ГБ); 2 CPU.
- EFI включён; Secure Boot выключен.
- Видео: **VMSVGA**, **128 МБ**, **3D acceleration включено**.
- Диск для первого live-теста необязателен; если создаёте — 30 ГБ достаточно для будущего установочного шага.
- Подключите NanOs ISO как оптический диск и загрузитесь с него.

## Ожидаемый результат

1. Проходит загрузка Kali live без изменения виртуального диска.
2. Пользователь live `kali` автоматически входит на tty1.
3. Запускается один рабочий стол — Hyprland; сверху виден Waybar.
4. `Super+Enter` открывает Foot, `Super+D` — меню Wofi, `Super+Q` закрывает окно.
5. Выход из Hyprland возвращает к live-shell, а не перезапускает композитор по кругу.

При необходимости входа в TTY используйте стандартную live-учётную запись Kali: `kali` / `kali`.

## Если вместо рабочего стола чёрный экран

Это считается провалом данного этапа, а не основанием добавлять второй DE. Переключитесь на TTY (обычно Host+F2 или Ctrl+Alt+F2), соберите `journalctl -b`, `systemctl status getty@tty1` и лог Hyprland из `$XDG_RUNTIME_DIR/hypr/`; crash report обычно лежит в `~/.cache/hyprland/`. Приложите вывод к проверке. Не переходите к установщику, пока live-сессия не будет подтверждена.
