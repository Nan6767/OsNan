# Установка NanOs

В `0.0.1-alpha` установщика пока нет: сначала проверяем live-загрузку и один Hyprland desktop в VirtualBox. После успешной проверки планируется отдельный этап с минимальным Calamares. До этого момента не используйте старые инструкции FlyArchOs — они относятся к прежней Arch-сборке.
